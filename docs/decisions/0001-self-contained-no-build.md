# 0001. 자기완결 · 무빌드 앱 구조

- **상태**: Accepted
- **날짜**: 2026-06-11 (소급 기록)

## 맥락
가벼운 토이 HTML 앱을 여러 개 모아두는 레포가 필요했다. 빌드 파이프라인 · 프레임워크는 토이 앱의 진입장벽과 유지보수 비용을 키운다.

## 결정
앱 1개를 자기완결 `apps/<slug>/index.html` 파일 하나로 둔다. 바닐라 HTML/CSS/JS만 쓰고 빌드 스텝 · 번들러 · 외부 의존성을 두지 않는다.

## 대안
- Vite/번들러 기반 멀티앱 — 토이 규모에 과함, 의존성 · 업그레이드 부담.
- 앱별 별도 레포 — 발견성 · 배포 일원화 손해.

## 결과
- (+) 파일 하나만 열면 앱 전체를 이해 · 수정 가능. 의존성 취약점 · 업그레이드와 무관.
- (+) 정적 호스팅(GitHub Pages)에 그대로 배포.
- (−) 코드 공유 · 재사용이 제한적(앱 간 복붙). 토이 규모에선 수용 가능한 트레이드오프.
