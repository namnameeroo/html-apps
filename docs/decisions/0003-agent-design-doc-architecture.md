# 0003. 에이전트 설계문서 아키텍처

- **상태**: Accepted
- **날짜**: 2026-06-11

## 맥락
AI 에이전트가 이 레포에서 반복 작업(앱 추가 · 리뷰 · 결정 기록)을 하려면, 코드에 없는 맥락(불변 규칙 · 과거 결정 · 할 일)과 재사용 가능한 에이전트 정의가 필요했다.

## 결정
- 사람 · 에이전트 공용 설계문서를 `docs/`에 둔다: `conventions.md`, `decisions/`(ADR), `todos/`, `reviews/`, `agents/`(인덱스).
- 레포 범위 에이전트의 **실행 정의**는 `.claude/agents/*.md`에 단일 소스로 둔다(Claude Code가 자동 인식 · 디스패치). `docs/agents/`는 목적 · 책임을 설명하는 인덱스만 두고 정의를 복제하지 않는다.

## 대안
- 에이전트 정의를 `docs/agents/`에 순수 문서로만 — 실제로 디스패치되지 않음.
- 정의를 `docs/`와 `.claude/`에 양쪽 복제 — 드리프트 위험(사용자 글로벌 원칙: 소스 한 곳만 수정).

## 결과
- (+) 에이전트가 실제로 "작동"하면서(`.claude/agents`) 설계 의도는 문서로 추적 가능.
- (+) 단일 소스라 드리프트 없음.
- (−) GitHub Pages 배포가 `docs/` · `.claude/` 마크다운도 함께 게시한다(비밀정보 없음, 링크 안 됨 — 수용).
