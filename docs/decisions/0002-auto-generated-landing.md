# 0002. 랜딩 페이지 자동 생성

- **상태**: Accepted
- **날짜**: 2026-06-11 (소급 기록)

## 맥락
앱이 늘어날 때 루트 랜딩(앱 목록)을 손으로 유지하면 누락 · 불일치가 생긴다.

## 결정
`scripts/build-index.mjs`가 `apps/*/index.html`을 스캔해 `<title>` · `<meta description>`을 추출하고 루트 `index.html`(카드 그리드)을 생성한다. 결과물은 `.gitignore`에 두고 CI(배포 시점)와 로컬에서 동일하게 생성한다.

## 대안
- 수동 유지 — 누락 · 드리프트.
- 정적 사이트 생성기 도입 — 0001의 무의존성 원칙과 충돌.

## 결과
- (+) 앱 추가 = 폴더 하나 추가로 끝. 랜딩은 자동 갱신.
- (+) 생성기는 Node 내장 모듈만 사용 — 무의존성 유지.
- (−) 루트 `index.html`은 생성물이라 직접 수정 불가(혼동 방지 위해 README · conventions에 명시).
