- [ ] **날짜 미지정 공유 URL의 타임존/날짜 의존 결함 해소** — 날짜 없는 URL이 보는 사람의 로컬 날짜로 당첨자를 바꿈. 공유 URL에 항상 `date`를 포함하거나 UX로 유도. _(리뷰 2026-06-11, 심각도 주요)_
- [ ] **URL 라우팅 3중화(query/hash/path) 단순화 결정** — 앱은 query 형식만 생성하므로 hash/path는 사변적 가능성. 단일 라우팅으로 줄일지 ADR로 결정. _(리뷰 2026-06-11, 심각도 주요)_
- [ ] **결정론 시드(FNV-1a)·시드 포맷의 "왜" 주석 추가** — 핵심 로직의 의도가 코드에 없어 향후 "단순화"로 결정론이 깨질 위험. _(리뷰 2026-06-11)_
