Review
+ 좋았던 점 3

멀티 모델을 한 세션에서 쓸 수 있음

ex.작업 중간에 Claude → Codex로 넘어갈 수 있음.

반복되는 패턴을 알아서 적용해줌

자가개선 효능감이 plain Claude Code CLI보다 잘 느껴짐. 컨텍스트 중간에 따로 skill을 만드느라 맥락을 흐리지 않아도 됨.

ex.FE 개발 → 구현 → 리뷰 → 최종 결과화면 스크린샷 코멘트 업로드. 반복 프롬프트 없이 2회 이상 쓰면 자동으로 진행함.

/handoff가 편함

알아서 handoff하고 세션을 새로 시작해줌.

− 걸렸던 점 4

사소한 수정도 러닝타임이 길어 전체 과정이 늘어짐

ex.기능 추가 → GJC로 장기 작업 구현 → 자체 QA 후 P5급 수정 한 건 요청 → 5분 소요. 개입해서 디테일을 올리는 후반 작업에서 특히 답답함.

MCP 연결 세팅을 새로 해야 함

쓰던 MCP 서버를 프롬프트에 분명히 요청해뒀는데도 별도 세팅 단계를 생략함. 그 결과 이후 과정에서 전부 누락됨.

Claude Code 내장 기능·기존 skill을 전부 지원하지는 않음

그만큼 drift가 생김. ex.grill-me, ultracode, model → 없거나 조금 다름.

토큰 소모가 큼 체감

비슷한 작업 기준 Claude Code CLI로 쓸 때보다 2~3시간 빨리 limit에 도달. 특히 ralplan·ultragoal처럼 GJC의 특장점으로 소개되는 내장 스킬을 쓸 때 차이가 확 느껴짐.

※ 토큰 소모 수치는 계측값이 아니라 2주간 써보며 느낀 체감치임.
